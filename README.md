# ARAL Shop

Премиальный концепт интернет-магазина одежды: Apple-презентация × высокая мода × Liquid Glass.

## Стек

- React 19 + Vite 8 + TypeScript
- Tailwind CSS 4
- Framer Motion
- Lucide icons

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`.

## Где что стоит (маркетинг)

1. **Hero** — манифест, не каталог. CTA ведёт к коллекции; вторичный — в лист ателье (высокий intent).
2. **Bento** — крупный halo-товар продаёт дом, мелкие SKU собирают чек.
3. **Ткань** — снимает возражение «дорого»: история как у чипа Apple.
4. **Lookbook** — полный образ поднимает AOV, модалка не убивает атмосферу.
5. **Лист ателье** — не скидочная рассылка, а доступ к дропу (дефицит).
